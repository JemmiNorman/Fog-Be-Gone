# No Fog Resource Pack

removes fog effects from Minecraft, allowing you to see your full render distance in all situations.

## Features
- Removes water fog (swimming)
- Removes lava fog (swimming in lava)
- Removes Nether fog (red haze)
- Removes End fog (purple haze)
- Removes powder snow fog
- Fully compatible with Sodium and other optimization mods
- No shader conflicts or compatibility issues

## Installation
1. Download the resource pack
2. Place it in your `.minecraft/resourcepacks/` folder
3. Enable it in the Resource Packs menu in Minecraft
4. You're done! Full visibility in all situations

## Compatibility
- Minecraft 1.21.x - 26.x
- Compatible with **Sodium**, Iris, Optifine, and all other rendering mods
- Works in single-player and multiplayer
